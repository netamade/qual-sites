# 発注書（追加）：再開発プランナーの日程欄の見出し出し分け（qual-sites）

2026-11-11、発注者：クロ。担当：Codex。
前提は PR #3 マージ済みの main（b95d3918）。

## 背景
template/engine.js の137行目付近で、CONFIG.scheduleNote がある場合の日程欄の見出しが「受験地・種類別の日程」に固定されている。再開発プランナーは年1回・全国一斉の試験で、この見出しが中身（「試験は年1回です。日程は年度ごとに実施団体が公表します。」）と合わない。eguchi の判断で、公開前に見出しを設定で出し分けられるよう直す。

## 修正内容
1. template/engine.js：scheduleNote がある場合の見出しを、CONFIG.scheduleTitle が設定されていればその値、なければ従来どおり「受験地・種類別の日程」とする。
2. template/titles.mjs：saikaihatsu の設定に `scheduleTitle: "試験日程"` を追加する。他のタイトルには追加しない（従来表示を維持）。
3. 全サイトを再生成する。

## 想定される差分の範囲（これ以外が出たら PR 本文で理由を書く）
- 全サイトの index.html（エンジンの差し込み内容と、それに伴うスクリプト内容の変化）と _headers（CSP のスクリプトハッシュ）。
- data.js は不変のはず。
- 表示が変わるのは再開発プランナーの日程欄の見出しだけ。他サイトの表示は従来どおり。

## 検証（実施して PR 本文に結果を書く）
- `node template/build.mjs --check` が成功すること。
- 再開発プランナーを開き、日程欄の見出しが「試験日程」になっていること。
- 消防のいずれか（例：shobo-4）を開き、見出しが「受験地・種類別の日程」のままであること。
