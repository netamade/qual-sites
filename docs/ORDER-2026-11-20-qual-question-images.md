# 発注書：資格サイト 問題画像の表示機能（2026-11-20）

対象リポジトリ：netamade/qual-sites
作業ブランチ：feat/qual-question-images（新規作成）

## 背景

- 資格サイト「電工」（qual-denko）に初めて問題を投入した（8問）。この8問はすべて共通の配線図「親図B」を前提とする問題だが、現在のサイトには問題に画像を表示する仕組みがなく、図が表示されない（eguchi 指摘、2026-11-20）。
- eguchi の決定：問題は表示したまま、図の対応を進める。
- 問題データには各問の「作図仕様」（テキストの描画指示）があるが、図の実物は未制作。**本発注はサイト側の受け口（表示機能）の実装のみ**で、図の制作は別工程。

## 実装内容

### 1. 問題データの画像フィールド

- 資格 payload（API 返却 JSON と静的 data.js の両方）に、任意フィールド `image` を追加できるようにする。
  - 形式：サイト内相対パス文字列（例 `"assets/q-6B-012.svg"`）。外部 URL は当面使わない。
  - `image` が無い問題では何も表示しない（完全な後方互換）。既存の問題データ・既存サイトの表示は一切変えない。

### 2. template/engine.js の改修

- `loadQuestions` の `add()` で `raw.image`（文字列の場合のみ）を保持する。
- 問題の表示画面（出題中・一問一答・模試のいずれの表示経路でも）で、`image` がある問題は問題文の直前に画像を表示する。
  - 配線図は細部が読めることが必須：表示幅は本文幅いっぱいを基本とし、タップ／クリックで原寸大（または拡大）表示できるようにする（モーダル／別表示の方式は実装側の判断でよいが、スマホで判読できること）。
  - 画像の読み込みに失敗した場合は、壊れた画像アイコンを出さず、代替テキスト（「図」）の表示にとどめる。
- Good/Bad・修正依頼ボタンの表示位置など、既存の表示要素は変えない。

### 3. 画像ファイルの配置規約と build

- 規約：`sites/<slug>/assets/` 配下に画像ファイルを置き、ビルド成果物にも同パスで含める。
- template/build.mjs が現状 assets をコピーしない場合は、コピー対象に追加する（対象は画像拡張子：svg／png／jpg／jpeg／webp）。
- サンプルとして、denko にダミーではないプレースホルダー画像は置かないこと（画像ファイルの配置は別工程で行う）。build の動作確認が必要な場合は一時ファイルで確認し、コミットには含めない。

### 4. CSP

- 画像は同一オリジン（相対パス）のみのため、CSP の変更は原則不要なはず。現行の img-src（'self' data: https://sq-feedback-api.sola-labo.workers.dev）が同オリジン画像を許可することを確認し、不足があれば 'self' の範囲で最小限に追加する。それ以外の CSP 変更はしない。

### 5. 全サイト再生成

- template の変更を全16サイトへ再生成して同一 PR に含める。**data.js は全サイト無変更**（生成物に差分が出る場合は理由を PR 説明に明記）。

## やらないこと

- 図の制作そのもの（別工程）。
- SKILL QUEST 側の改修（対象外。資格サイト template のみ）。
- 認証コードまわりの仕様変更。

## 完了条件

- PR を作成し、次を PR 説明に明記すること：
  - image フィールドの仕様（形式・表示位置・拡大方式）
  - ローカル検証の結果：image 付きダミー問題で表示・拡大・読み込み失敗時の代替表示を確認したこと、image なし問題の表示が従来どおりであること、CSP 違反が出ないこと
  - data.js に差分が無いことの確認方法
- 検証はローカルで実施し、本番デプロイはしないこと（デプロイはクロ側で行う）。
