# 発注書：難易度の★表示と正答率メーターの追加（2026-11-26）

## 目的
資格サイト（qual-sites）の出題画面で、難易度と予想正答率をもっと直感的に見せる。
- 難易度に ★ の数を追加する
- 正答率（出題データ）にメーター（バー）を追加する

## 現行の状態（template/engine.js、935行版で確認済み）
- 出題画面の `quiz-meta`（823行目付近）に、ラベルの span が並ぶ。
  - 「難易度 」＋ question.difficulty（827行目）
  - 「正答率（出題データ） 」＋ publishedRate ＋ "%"（829〜831行目、publishedRate は raw.correct_rate 由来、257行目）
- difficulty の実データは 1〜3 の3段階（D1 の qual-denko 58問・qual-shobo-4 354問で実測：1/2/3 のみ）。
- correct_rate の実データは 35〜88 の数値（パーセント）。

## 実装仕様

### 1. 難易度の★表示
- difficulty が 1〜3 の数値の場合、ラベルを「難易度 」＋ ★の繰り返し（difficulty 個）＋ ☆の繰り返し（3 − difficulty 個）にする。
  - 例：difficulty=1 → 「難易度 ★☆☆」、difficulty=2 → 「難易度 ★★☆」、difficulty=3 → 「難易度 ★★★」
- difficulty が数値でない・未設定の場合は、現行の表示（「難易度 」＋値、または「未設定」）をそのまま維持する。
- ★の色は既存デザイン（D案：黄色 #ffd400 × 黒 × オレンジ #ff4d1c）に合わせ、視認できる色にする（例：#ff4d1c または #ffd400 に黒縁相当の扱い）。☆はグレー系でよい。

### 2. 正答率のメーター
- publishedRate が数値の場合、「正答率（出題データ） 70%」のテキストは残し、その横（同じ span 内）にメーターを追加する。
  - メーターは横幅 64px 程度のトラック（背景グレー系）＋値の幅（％）のフィル（デザインに合う色、例：#ff4d1c）で構成する。
  - フィルの幅は publishedRate を 0〜100 にクランプした値を使う。
- publishedRate が数値でない場合はメーターを出さず、現行どおりテキストのみ。
- 「正答率（自分）」のラベルにはメーターを付けない（対象は出題データ側だけ）。

### 3. 共通
- quiz-meta のレイアウト（span の並び）が崩れないようにする。スマホ幅でも横溢れしないこと。
- 既存の他の表示・動作（採点、解説、Good/Bad、修正依頼、認証コード）には変更を加えない。

## 対象ファイルと進め方
- 変更対象は template/engine.js と、スタイル追加が必要な場合は template/index.html（CSS）のみ。
- build.mjs で全16サイトを再生成し、同一 PR に収める。**data.js は全サイト無変更**であること。
- 作業ブランチ：feat/qual-difficulty-stars-rate-meter
- PR を作成するところまで。マージと本番デプロイ（Cloudflare Pages）はクロ側で行う。
