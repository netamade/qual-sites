# 資格サイト「ガワ」共通仕様 v1（2026-11-11、クロ作成）

## 目的
書籍連動型の練習サイトについて、作問の進み具合に関係なく**全タイトル分の器（ガワ）を先に作る**（eguchi決定 2026-11-11）。中身（問題）は後から data.js を差し替えて順次追加する。ガワは Cloudflare Pages（不特定多数向け＝flare、2026-11-11 の使い分け）へ置き、資格サイトスペース（zi-ge-saito）に「ガワ完成・作問中」として並べる。

## 前提・正本
- 機能の正本は「資格問題集-練習サイト共通仕様-v1.md」（同フォルダ）。本書はその**ガワ実装への落とし込み**であり、矛盾する場合は共通仕様v1が優先。
- 実装の土台は社員用サイト（mansion-kanrishi／kanri-gyomu-shunin）の機能追加第2弾で実証済みの構成（カウントダウン／モード説明／分野別レーダー／合格確率目安／分野別コーナー／一問一答コーナー＋花丸バツ）。コードの流用可。ただし社員用とは**別サイト・別データ**として作る（データ・localStorageキーを混ぜない）。
- 花丸／バツ フィードバックマークは最初から組み込む（共通仕様v1 第10節のSVG・CSSをそのまま使う）。

## 構成（1タイトル＝1フォルダ＝1デプロイ単位）
- `index.html`（単一ファイルにUI・エンジン内包、外部CDN・外部フォント禁止）
- `data.js`（問題データ。ガワ段階では空：`window.EXAM_DATA = {"sets": [], "questions": []}` 相当＋タイトル設定を内包。形式は社員用サイトの data.js と互換にし、作問側がそのまま投入できる形にする）
- `_headers`（セキュリティヘッダ：nosniff／X-Frame-Options DENY／Referrer-Policy no-referrer／CSP default-src 'self' 系）
- タイトルごとの差分は**設定オブジェクト**（タイトル名・書籍名・試験名・試験日・分野一覧・合格目安ライン・localStorage接頭辞・テーマ色）に集約し、テンプレート1本から全タイトル分を生成する。

## ガワ段階の画面要件
- トップ：サイト名＋「『（書籍名）』連動 練習サイト」表記、試験日カウントダウン（設定日まで動的計算）、モード説明、分野別レーダー枠（データなし表示）、合格目安ライン表示。
- 4モード（ランダム／分野別 × 択一／一問一答）＋毎日のランダム出題の導線を実装。問題0件のときは「問題は順次追加中です」と正直に表示し、エラーにしない。
- 学習記録は localStorage（接頭辞はタイトル別：例 `book:takken:`）。問題が後から増えても記録形式は壊さない。
- フォントはゴシック体統一。デザインは共通仕様どおりスタイリッシュに（社員用サイトの見た目をそのまま流用しない。書籍連動らしい配色に変える）。
- 書籍への案内枠（「本書の問題はサイトでも練習できます」の逆＝サイト側に書籍情報枠。書籍未発刊の間は「書籍は発刊準備中」と表示）。

## デプロイ・運用
- 置き場所は Cloudflare Pages のダイレクトアップロード（プロジェクト名は内容を特定できない文字列。割当はデプロイ時にクロが行う）。
- コードの置き場所は GitHub の1リポジトリにタイトル別フォルダで集約（コード自体は漏れてよいデータ）。
- 公開前のセキュリティレビューを完了条件とする（共通仕様どおり）。
- 資格サイトスペースへの掲載はガワがデプロイできたタイトルから順に（状態表示は「ガワ完成・作問中」→問題が入り書籍が発刊されたら「公開中」）。
